# DID SCID Method Specification

This repository holds the Trust Over IP (ToIP) Technology Stack Working Group's specification of the `did:scid` DID method.

The rendered specification is published at <https://trustoverip.github.io/tswg-did-scid-method-spec/>.

The specification is written in Markdown under [`spec/`](spec/) and rendered with [Spec-Up-T](https://trustoverip.github.io/spec-up-t-website/), following the [ToIP specification template](https://github.com/trustoverip/toip-template). Every push to `main` re-renders the specification and deploys it to the `gh-pages` branch through the `render-and-deploy` workflow.
